# Sample set (synthetic)

These two cases are **made up**. The "transcripts" and "minutes" were written by hand, with deliberate errors
(misheard words, English written in Devanagari, one missed action, one wrong owner), so the report shows non-trivial
numbers. The set only proves that the harness runs. It says nothing about how Debrief performs on real meetings.

Real numbers need your own clips: see `docs/EVAL.md` for how to build a set from recordings of your own meetings.
