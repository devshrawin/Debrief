# Libraries.dev inventory (Phase 0)

Source: `Libraries.dev-slim.zip` (React 18 libraries by Jakub Antalik). Each package is MIT. `metal-fx` also carries an Apache-2.0 NOTICE for Paper Shaders' `liquidMetal` shader, which must ship with it.
Sizes were measured here with esbuild 0.24 (`--bundle --minify`). React/ReactDOM/three were left external unless stated. Chrome reads extension files from disk uncompressed, so **min** is the number that matters at runtime; **gz** only affects the store download.

| Package (version) | What it does | Public API / props we would use | Renderer | Size min / gz | Idle cost (from source) | React-free path? |
|---|---|---|---|---|---|---|
| **border-beam** 1.4.0 | Animated glow around a box: travelling beam (`sm`, `md`, `line`) or breathing glow (`pulse-inner`, `pulse-outside`) | `size`, `colorVariant` (`colorful` / `mono` / `ocean` / `sunset`), `theme` (`dark` / `light` / `auto`), `strength` 0–1, `duration`, `active` (fades in/out), `borderRadius`, `brightness`, `saturation`, `hueRange`, `staticColors`, `glowSize`, `onActivate` / `onDeactivate` | CSS: conic and radial gradients, masks, `@property`; the pulse types use one shared ~30 fps rAF loop that writes CSS variables | Whole library 82.8 KB / 12.7 KB. `styles.ts` + `pulseDriver.ts` alone: 79.2 KB / 11.2 KB. **CSS generated ahead of time for one preset and theme: 6.6–13.0 KB raw** | Rotate types repaint every frame while active; the pulse loop pauses when inactive, offscreen or under reduced motion | **Yes.** `generateBeamCSS()` and `registerPulseInstance()` don't import React. **For scale:** React 18 + ReactDOM in production builds measure 142 KB min / 45.5 KB gz. The current bundles are `popup.js` 18 KB, `pill.js` 31 KB, `mom.js` 173 KB and `options.js` 107 KB.

**Not used, on purpose:**
- `thinking-orbs` gravity and `metal-fx` cursor light: both hide the OS cursor and draw a raster cursor instead. That is wrong for a work tool and fails with enlarged system cursors.
- `metal-fx` proximity reflections: they need neighbouring elements in dark mode only.
- liquid-gooey Melt, Bend and dissolve: Debrief has nothing these would improve.
